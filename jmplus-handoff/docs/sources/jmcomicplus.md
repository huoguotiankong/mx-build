# 禁漫天堂 Plus（JMComic Plus）维护记录

## 定位

独立的 Tachiyomi / Mihon / Komikku 兼容扩展，模块：`src/zh/jmcomicplus/`。

本源不覆盖 Keiyoushi 上游 `禁漫天堂`，目标是在保持普通宿主兼容的前提下，为 MX 宿主增加账号、书评、章评与增强详情能力。

## 首版目标

- APP/API + Web 双线路，自动模式优先最近成功线路。
- APP API 节点自动发现、缓存和故障回退。
- Web 动态域名自动更新、缓存、手动域名覆盖与故障回退。
- 首页/最新/搜索/分类/排序/时间/搜索范围。
- 详情、目录、正文、相关作品。
- JM 图片分流与图片反混淆。
- APP/API 账号登录（AVS）+ Web Session 登录；敏感信息仅保存在用户设备偏好中。
- MX `AccountSource` 账号状态。
- MX `CommentSource`：作品书评 + 章节评论；支持读取、楼中楼读取、发表和回复。
- **没有段评能力，不实现段落评论入口。**
- MX `MangaDetailSource`：作者、原作、登场人物、分类、标签可点击跳转搜索，同时显示作品数据和当前线路。

## 路线与协议参考

### Web

优先从动态列表/跳转页/发布页发现可用域名，并保留静态候选域名作为回退。用户可以在源设置中手工覆盖 Web 域名。

### APP/API

动态节点来自官方客户端使用的加密域名配置服务器，失败时回退到已知 API 候选节点。API 请求使用客户端时间戳 Token 及 AES 数据解包，登录态使用 AVS。

### 评论

- 书评目标 ID：album ID。
- 章评目标 ID：photo/chapter ID。
- 读取优先 APP `/forum`，Web 评论分页接口作为回退。
- 发表评论/回复使用 Web 评论写接口，因此写操作要求有效 Web 登录态。

## 图片

对 `/media/photos/<photoId>/...` 使用 JM 纵向切片反混淆规则；220980 以前不处理，之后根据章节 ID 和图片编号计算行数。该算法与当前 Keiyoushi 上游禁漫天堂实现保持一致。
